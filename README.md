# 📐 CAD Practice & Exercise Series

Welcome to the **CAD Practice & Exercise Series**!

This repository is a structured collection of real-world mechanical design challenges, detailed 2D engineering blueprints, and parametric modeling exercises. Whether you are learning ***SolidWorks***, ***Fusion 360***, ***AutoCAD***, or ***Inventor***, these exercises are designed to help you transition from basic software operations to production-ready design practices.

---

## 🎯 What You'll Find Here

Each exercise in this series includes:
* **The Blueprint:** High-resolution 2D technical drawing sheets with fully-defined dimensions, section views, and ISO callouts.
* **Skill Focus:** Specific highlights on key CAD techniques (e.g., Revolve, Loft, Shell, Draft Angles, Assembly Mates).
* **Modeling Tips:** Guidance on feature tree efficiency and best practices.
* **Downloadable Assets:** Free high-res PDF drawings and universal `.STEP` solution models.

---

## 🛠️ Software & Tools
* **CAD:** SolidWorks 2021
* **Rendering:** SolidWorks Visualize / PhotoView 360

---

## 💡 How to Use These Exercises

1. **Pick a Challenge:** Select an exercise from the index above.
2. **Download the Blueprint:** Open the PDF drawing and study the dimensions, section views, and geometric tolerances.
3. **Build the Model:** Open your CAD software of choice and build the part or assembly independently.
4. **Compare & Verify:** Download the provided `.STEP` file or check `images` and `.pdf` drawing sheet to confirm overall accuracy.

---

## 📁 Repository Structure
  * 📁`Exercise` - Contains all file respective to this Project/Exercise.
    * 📁`files` - Native or neutral CAD files (`.SLDPRT`, `.SLDASM`, `.STEP`) and `.pdf` drawing sheet.
    * 📁`images` - High-quality renders and technical drawing captures.
    * `README` - Markdown documentation of design intent and feature trees.
